Projetos Relevantes

Sistema de Monitoramento e Gerenciamento de Gado

Projeto Startup da residência do programa Bolsa Futuro Digital. Desenvolvi uma API Backend em Python/FastAPI e PostgreSQL. O sistema oferece uma plataforma útil para pecuaristas visualizarem e gerenciarem a qualquer momento e de forma fácil seu gado, com informações analíticas e alertas de variação de peso, visualização por fazenda e pesagens automaticamente processadas a partir de dimensões do gado capturadas por sensores/camêras.

Sistema de Academia

Projeto integrador do Programa Bolsa Futuro Digital. Desenvolvi uma API Backend em JavaScript/NestJS e MySQL. O sistema oferece uma plataforma completa de academia, com controle de acesso por perfil (Admin/Recepção, Professor e Aluno), planos de exercícios, monitoramento de progressão e gamificação por pontos dos alunos.

Projetos Pessoais

L4RI

Bot feito em JavaScript para a plataforma Fluxer. Possui funcionalidades de procura de conteúdo na internet em geral, como imagens, vídeos, páginas da wikipedia, entre outros, Integração com LLMs via @Groq para gerar respostas e interagir com os usuários, e geração de imagens via @pollinations.ai, e avisos sobre jogos grátis na Steam e Epic Games Store.

AAQT

Um programa feito em C++ usando framework Qt que espelha a funcionalidade do AATool, onde o diferencial é uma versão compatível com sistemas Linux.
